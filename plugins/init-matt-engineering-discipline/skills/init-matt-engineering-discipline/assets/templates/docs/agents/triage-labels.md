# Triage Labels

Matt Pocock skills 使用五个标准 triage role。本文件把这些 role 映射到本仓库 GitHub Issues 中实际使用的 label。

| Matt Pocock role | GitHub label | 中文含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者初筛 |
| `needs-info` | `needs-info` | 等待提报者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格足够清楚，可交给 agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人类工程师处理 |
| `wontfix` | `wontfix` | 明确不处理 |
